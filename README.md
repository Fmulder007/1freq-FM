# 1freq-FM — синтезатор частоты на ATmega328 + Si5351

Компактный модуль для замены кварцевого генератора в старых радиостанциях.
Два варианта прошивки — под разные задачи.

---

## Содержание репозитория

```
1freq-FM/
├── Code/
│   ├── 1freq-FM5/    — прошивка: две фиксированные частоты, переключение кнопкой
│   └── 1freq-FM6/    — прошивка: плавная перестройка потенциометром
├── LAY/              — чертёж печатной платы (SprintLayout 6)
└── PHOTO/            — фотографии готового модуля
```

---

## Вариант 1: Две частоты, переключаемые кнопкой (1freq-FM5)

Стационарный режим: две фиксированные частоты, переключение кнопкой.
Подходит для радиостанций с фиксированными каналами (например, LSB/USB
или два независимых канала).

### Параметры EEPROM

Две строки по 16 байт:

| Адрес  | Параметр  | Описание                |
|--------|-----------|-------------------------|
| `0x00` | `UP=xxxxxxx\0` | Частота канала UP, Гц |
| `0x10` | `DN=xxxxxxx\0` | Частота канала DN, Гц |

### Подключение

- **Кнопка** — между выводом управления и землёй.
  Внутренняя подтяжка МК включена программно.
  При замыкании кнопки частота переключается между UP и DN.
- **Si5351** — питание 3.3 В, I2C к ATmega328 напрямую.

### Генератор EEPROM

Используется `make_eeprom.cmd` с двумя параметрами (UP и DN).
Скрипт читает существующий `eeprom.hex`, показывает текущие значения,
спрашивает новые и записывает Intel HEX.

### Пример

Для радиостанции с двумя каналами на 7 МГц:

- `UP=7040000` — верхний канал
- `DN=7020000` — нижний канал

## Вариант 2: Перестройка потенциометром (1freq-FM6)

Плавная перестройка частоты потенциометром — замена КПЕ.
Подходит для радиостанций, где нужен плавный ход по диапазону.

### Параметры EEPROM

Три строки по 16 байт:

| Адрес  | Параметр       | Описание                                  |
|--------|----------------|-------------------------------------------|
| `0x00` | `FR=xxxxxxx\0` | Базовая (центральная) частота, Гц         |
| `0x10` | `BW=xxxxxx\0`  | Полная ширина диапазона, Гц (±BW/2 от FR)  |
| `0x20` | `ST=xxxx\0`    | Количество шагов (0 = 1024, прямой режим)  |

### Логика перестройки

- Шаг 0 (0 В):      `FR − BW/2` (нижняя граница)
- Шаг ST (VCC):     `FR + BW/2` (верхняя граница)
- Центр (середина): `FR`
- Размер шага:      `BW / ST` (ровно)

### Подключение

- **Потенциометр 1 кОм:** крайние выводы — GND и 3.3 В,
  средний — на ADC0 (PC0) через резистор 10 кОм.
- **RC-фильтр:** конденсатор 100 нФ между ADC0 и землёй.
  RC-фильтр (10 кОм + 100 нФ): τ = 1 мс, fc ≈ 159 Гц.
- **AVCC:** подключён к 3.3 В (обязательно для работы АЦП).
- **AREF:** конденсатор 100 нФ на землю (напряжение не подавать).
- **Si5351:** питание 3.3 В, I2C к ATmega328 напрямую.

### Антидребезг (трёхступенчатый)

1. **Аппаратный RC-фильтр** — подавление наводок и ВЧ-помех (10 кОм + 100 нФ).
2. **Программное усреднение** — 4 последовательных замера ADC.
3. **Зона нечувствительности** — изменение ADC менее чем на 2 отсчёта игнорируется.

### Генератор EEPROM

Используется `make_eeprom.cmd` с тремя параметрами (FR, BW, ST).
Скрипт читает существующий `eeprom.hex`, показывает текущие значения,
спрашивает новые и записывает Intel HEX.

### Пример

Для диапазона 1.95 МГц ± 50 кГц с шагом 500 Гц:

- `FR=1950000`  — центр диапазона
- `BW=100000`   — ширина 100 кГц
- `ST=200`       — 200 шагов

Результат: перестройка от 1900000 до 2000000 Гц с шагом ровно 500 Гц.

### Калибровка

Калибровочный коэффициент не используется. После сборки достаточно
измерить реальную частоту и вписать поправку прямо в FR.
Например, если кварц Si5351 «убежал» на +30 Гц — пишем `FR=1950030`.

## Общее для обоих вариантов

### Питание

- **3.3 В** — единое питание для МК и Si5351.
  Никаких преобразователей уровня, всё напрямую.
  ATmega328P при 3.3 В гарантированно работает до 8 МГц,
  при 1 МГц (фьюз CKDIV8) — запас огромный.

### Кварц Si5351

- Частота кварца задаётся в коде: `#define Si_Xtall_Freq 27007840UL`.
- При замене кварца на другой — поправить константу в прошивке.

### Печатная плата

- Чтёж платы — в каталоге `LAY/`, формат SprintLayout 6.
- Принципиальная схема не приводится — она проста и понятна из чертежа платы.

### Прошивка

- **Flash:** через AVRDUDE_PROG 3.3 (или avrdude), память: Flash, формат: Intel HEX.
- **EEPROM:** через AVRDUDE_PROG 3.3, память: EEPROM, формат: Intel HEX,
  файл: `eeprom.hex` (генерируется `make_eeprom.cmd`).

### Фьюзы

| Фьюз      | Значение | Описание              |
|-----------|----------|-----------------------|
| Low       | `62`     | 1 МГц, CKDIV8         |
| High      | `D1`     |                       |
| Extended  | `FD`     |                       |

### Библиотеки

- `si5351a.h` — драйвер Si5351
- `EEPROM.h` — стандартная библиотека Arduino
