# Внешние инструменты

Для готовой Windows-сборки нужны:

- AVRDUDE 8.3, Windows MSYS2 MinGW x64 — используется именно MinGW-вариант, поскольку сборка MSVC из того же выпуска не содержит libserialport, необходимый для Arduino Nano по COM-порту.
- Zadig 2.9 — запускается только по команде пользователя для настройки драйвера USBasp.

Выполните prepare-tools.ps1 на машине сборки с доступом в Интернет. Скрипт скачивает официальные архивы, проверяет SHA-256 архива AVRDUDE и цифровую подпись Zadig, распаковывает AVRDUDE вместе с DLL и avrdude.conf, а исходники сторонних инструментов сохраняет в Licenses/Source.

Скрипт не устанавливает USB-драйвер и не меняет настройки устройств Windows.

AVRDUDE MinGW должен оставаться целиком в Tools/AVRDUDE: нельзя переносить один avrdude.exe отдельно от DLL.
