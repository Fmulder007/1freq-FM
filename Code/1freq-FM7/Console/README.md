# 1freq-FM Console

Windows-консоль для настройки и прошивки микросинтезатора на Si5351.

Приложение работает с каталогом прошивок из `Config/devices.json`. Выбор микроконтроллера делает пользователь: автоматического определения по сигнатуре нет. Для всех операций AVRDUDE запускается с `-F`, поэтому проверка соответствия сигнатуры выбранному профилю отключена.

## Меню

1. Создать или изменить настройки EEPROM FM7.
2. Прошить выбранный микроконтроллер: Fuse-биты (по выбору), Flash и EEPROM.
3. Записать только EEPROM выбранного микроконтроллера.
4. Считать EEPROM выбранного микроконтроллера в резервную копию.
5. Запустить Zadig для настройки USB-драйвера USBasp.

Перед полной прошивкой программа сохраняет текущую EEPROM, затем при выборе пользователя записывает указанные в профиле Fuse-биты, прошивает Flash и проверяет Flash, после чего записывает и проверяет свежую EEPROM-конфигурацию FM7.

Если в профиле заданы Fuse-биты, вариант 1 выбран по умолчанию: при нажатии Enter профильные значения будут записаны и проверены. Чтобы сохранить текущие Fuse-биты, явно выберите вариант 2. В профилях FM7 включён EESAVE — EEPROM сохраняется при Chip Erase.

Если в профиле отсутствует объект `fuses`, Fuse-биты не записываются. Если указаны только некоторые поля (например, LFUSE и HFUSE), программа работает только с ними.

## Каталог прошивок

Список меню формируется автоматически из объекта `firmwares` в `Config/devices.json`. Ключ каждой записи — точное имя HEX-файла в каталоге `Firmware`.

Пример записи:

```json
"Example.hex": {
  "name": "ATmegaXXX",
  "avrdudePart": "mXXX",
  "flashBytes": 32768,
  "eepromBytes": 1024,
  "eepromFormat": "FM7",
  "supportedProgrammers": ["usbasp", "arduino-isp"],
  "fuses": {
    "low": "62",
    "high": "D1",
    "extended": "FF"
  },
  "notes": "MiniCore, тактирование 1 МГц"
}
```

Для добавления следующего МК достаточно положить его HEX в `Firmware` и добавить профиль в JSON. Программа не требует изменений исходного кода или повторной публикации. Новый профиль будет использоваться с указанными в JSON `avrdudePart`, fuse-значениями и списком программаторов.

Текущие профили собраны под MiniCore. Если выбранного `avrdudePart` нет в штатном `avrdude.conf` поставляемой версии AVRDUDE, его описание нужно добавить в `Config/avrdude-extra.conf`.

**Важно:** автоматическая проверка сигнатуры намеренно отключена. Пользователь сам выбирает профиль; неправильный выбор может привести к повреждению содержимого подключённого МК.

## EEPROM FM7

Параметры EEPROM описаны в `eepromLayout` в `Config/devices.json`:

| Адрес | Метка | Назначение |
|---:|---|---|
| 0x00 | XT= | Опорная частота кварца Si5351, Гц |
| 0x10 | MD= | Режим 5 или 6 |
| 0x20 | F1= | Частота при минимальном напряжении PC0 |
| 0x30 | F2= | Частота при максимальном напряжении PC0 |
| 0x40 | ST= | Количество шагов, 0 = 1024 |

Одна запись занимает 16 байт; весь блок настроек — 80 байт. Пункт меню 1 сохраняет введённые значения в `Data/last-settings.json` и каждый раз генерирует `Data/eeprom.hex`. Этот файл не является прошивкой Flash и не входит в список МК.

Диапазоны параметров:
- XT: 5 000 000…110 000 000 Гц;
- MD: 5 или 6;
- F1 и F2: 15 000…300 000 000 Гц;
- ST: 0…1024.

Значения по умолчанию: XT=27007840, MD=5, F1=2000000, F2=1000000, ST=0.

## Программаторы

### USBasp

Используется USBasp со стандартной прошивкой. Для всех команд явно задаётся ISP SCK 32 кГц параметром `-B 32kHz`. Старые клоны, не поддерживающие программное переключение SCK, могут потребовать аппаратный режим Slow SCK или обновление прошивки USBasp.

Zadig находится в `Tools/Zadig.exe`. Он запускается только через пункт меню 5. Выбирать в Zadig следует USBasp; не меняйте драйверы других USB-устройств.

### Arduino Nano как ISP

Nano должна быть заранее подготовлена официальным скетчем ArduinoISP. Приложение работает через STK500v1 на 19200 бод и COM-порт.

Частота SCK задаётся в самом скетче ArduinoISP параметром `SPI_CLOCK`; AVRDUDE не может изменить её для STK500v1. Стандартное значение около 166,7 кГц подходит для наших текущих МК на 1 МГц (четверть частоты МК — 250 кГц). Для будущих МК с частотой ниже примерно 667 кГц перед прошивкой следует уменьшить `SPI_CLOCK` и повторно загрузить ArduinoISP в Nano.

При открытии COM-порта Nano может сбрасываться. После загрузки ArduinoISP обычно устанавливают конденсатор около 10 мкФ между RESET и GND Nano-программатора. Не соединяйте два независимых источника питания; общая земля обязательна.

Разводка Nano → целевой AVR:

| Nano | Целевой МК |
|---|---|
| D10 | RESET |
| D11 | MOSI |
| D12 | MISO |
| D13 | SCK |
| GND | GND |
| 5V | VCC только при питании от Nano |

В каждом профиле JSON отдельно указан список разрешённых программаторов.

## Резервные копии

Резервные копии EEPROM сохраняются в `Backup` с датой, временем и именем HEX-профиля. При полной прошивке чтение EEPROM обязательно выполняется до записи Flash.

## Сборка и публикация

1. Установить .NET 10 SDK на Windows x64.
2. Запустить `publish.cmd`.
3. Скрипт при необходимости скачает инструменты, проверит SHA-256 AVRDUDE и цифровую подпись Zadig, затем соберёт приложение.
4. Готовый ZIP появится в `dist/1freq-FM-Console-win-x64.zip`.

Пользователю готового ZIP не нужен установленный .NET Runtime. Arduino IDE нужна только для самостоятельной подготовки Nano как ArduinoISP.

## Проверка

Команда `1freq-FM.exe --self-test` проверяет структуру JSON, настройки EEPROM, наличие каждого HEX из включённых профилей, его контрольные суммы и выход за объём Flash. Реальная работа программаторов проверяется отдельно на подключённом оборудовании.
