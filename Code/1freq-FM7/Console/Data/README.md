# Data

Во время работы программа создаёт здесь:

- `last-settings.json` — последние введённые параметры EEPROM FM7;
- `eeprom.hex` — Intel HEX с текущими настройками FM7, который генерируется пунктом меню 1.

`eeprom.hex` — не прошивка микроконтроллера. Это отдельный образ области EEPROM объёмом 80 байт; он используется при записи настроек в микроконтроллер.

Эти файлы можно удалить, чтобы при следующем запуске начать с параметров по умолчанию из `Config/devices.json`. Сам файл каталога программа не перезаписывает.
