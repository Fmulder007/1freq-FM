# Прошивки микроконтроллеров

Сюда помещаются отдельно скомпилированные и предварительно проверенные HEX-файлы:

| Профиль в Config/devices.json | Имя файла |
|---|---|
| ATmega168 | ATmega168.hex |
| ATmega168P / ATmega168PA | ATmega168P.hex |
| ATmega328P | ATmega328P.hex |
| ATmega328PB | ATmega328PB.hex |

Файлы прошивок намеренно не подменяются друг другом. Приложение сверяет сигнатуру подключённого МК с devices.json и использует только HEX, указанный в найденном профиле.

Перед добавлением HEX проверьте его сборку и размер Flash. В частности, поддержку ATmega168 и ATmega328PB необходимо подтвердить отдельными испытаниями. В этом исходном комплекте бинарные прошивки пока не приложены.

eeprom.hex содержит начальные параметры FM7. После изменения настроек программа сама пересоздаёт этот файл.
