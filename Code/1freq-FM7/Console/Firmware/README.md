# Firmware

Здесь находятся только прошивки Flash микроконтроллеров. Каждый файл должен иметь отдельную запись с таким же именем в `Config/devices.json`, в объекте `firmwares`.

| Имя HEX | Профиль |
|---|---|
| `ATmega168.hex` | ATmega168 |
| `ATmega168P.hex` | ATmega168P / ATmega168PA |
| `ATmega328P.hex` | ATmega328P |
| `ATmega328PB.hex` | ATmega328PB |

Все текущие варианты собраны для MiniCore на частоту ядра 1 МГц.

## Добавление новой прошивки

1. Соберите скетч для нужного AVR из поддерживаемых MiniCore.
2. Положите полученный HEX в этот каталог под новым уникальным именем.
3. Добавьте в `Config/devices.json` запись в `firmwares`, используя это имя как ключ.
4. Заполните название МК, `avrdudePart`, объёмы Flash и EEPROM, список программаторов и доступные fuse-значения.
5. Запустите `1freq-FM.exe --self-test`: программа проверит наличие и размер HEX, а также контрольные суммы Intel HEX.

После добавления записи новый вариант автоматически появится в меню. Перекомпилировать консоль для добавления нового профиля не требуется.

В `Firmware` не размещается `eeprom.hex`: он генерируется пунктом меню 1 и хранится отдельно в `Data/eeprom.hex`.
