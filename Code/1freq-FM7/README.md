# 1freq-FM7 — универсальный синтезатор AVR + Si5351

FM7 объединяет два принципа управления из FM5 и FM6 в одну прошивку.
Способ интерпретации напряжения на управляющем входе выбирается параметром MD
в EEPROM. Для смены режима перепрошивать микроконтроллер не требуется.

Прошивка рассчитана на одну общую реализацию для четырёх ATmega под MiniCore
и LGT8F328P под собственным ядром LGT8Fx.

## Состав каталога

- 1freq-FM7.ino — основная логика FM7.
- platform.cpp и platform.h — небольшая адаптация особенностей Arduino-ядер.
- si5351a.cpp и si5351a.h — библиотека Si5351 из GSSx11.
- i2c.cpp и i2c.h — аппаратный TWI-драйвер FM7.
- make_eeprom.cmd — запуск генератора EEPROM.
- make_eeprom.ps1 — генератор файла Intel HEX.
- eeprom.hex — пример конфигурации.
- README.md — описание версии.

## Поддерживаемые микроконтроллеры и ядра

| Микроконтроллер | Arduino core | Вариант |
|---|---|---|
| ATmega168 | MiniCore | ATmega168 |
| ATmega168P / 168PA | MiniCore | ATmega168, вариант 168P / 168PA |
| ATmega328P | MiniCore | ATmega328, вариант 328P / 328PA |
| ATmega328PB | MiniCore | ATmega328, вариант 328PB |
| LGT8F328P | LGT8Fx | LGT8F328, вариант корпуса/платы по фактическому исполнению |

Для ATmega используется MiniCore. Для LGT8F328P используется отдельное ядро
LGT8Fx; выбирать MiniCore для него нельзя. В настройках LGT8Fx необходимо
выбрать источник тактирования и делитель, соответствующие реальной плате.

Официальные проекты ядер:
- MiniCore: https://github.com/MCUdude/MiniCore
- LGT8Fx: https://github.com/dbuezas/lgt8fx

Поддержка сборки исходника не означает автоматическую поддержку программирования
LGT8F328P приложением Console. У LGT8F328P та же сигнатура, что у ATmega328P,
поэтому выбор алгоритма программирования и определение такого чипа требуют
отдельного решения.

## Единый управляющий вход

Управляющий вход задаётся через Arduino-обозначение A0. В используемых вариантах
это PC0 / ADC0. Привязка к цифровому номеру 14 убрана: соответствие Arduino-номера
физическому выводу определяет выбранный вариант платы.

В обоих режимах прошивка:
- настраивает A0 как обычный вход INPUT;
- не включает внутреннюю подтяжку;
- измеряет напряжение АЦП;
- усредняет четыре последовательных измерения.

В ядре LGT8Fx разрешение АЦП явно устанавливается в 10 бит. Поэтому основная
логика FM7 во всех вариантах получает один диапазон: 0...1023.

Внешняя схема должна самостоятельно задавать напряжение на A0. Оставлять вход
неподключённым нельзя: плавающий вход не обеспечивает определённого состояния.

## Режим MD=5 — два фиксированных значения

Напряжение на A0 интерпретируется как переключатель:

- минимальное напряжение выбирает F1;
- максимальное напряжение выбирает F2;
- промежуточные значения не формируют промежуточную частоту.

Для защиты от колебаний около порога применяется гистерезис:
- ADC <= 480 — переход к F1;
- ADC >= 544 — переход к F2;
- между порогами сохраняется предыдущее состояние.

При включении исходное состояние определяется относительно ADC=512.
Параметр ST хранится в EEPROM, но в режиме MD=5 не используется.

Для повторения прежней логики FM5 параметр F1 задаёт частоту UP при низком
уровне напряжения, а F2 — частоту DN при высоком уровне напряжения.

## Режим MD=6 — плавная перестройка

Весь диапазон АЦП преобразуется в частоту:

- ADC=0 соответствует F1;
- ADC=1023 соответствует F2;
- промежуточные значения выбирают шаги между этими частотами.

ST=0 означает 1024 шага, как в прежней FM6.
Значения ST от 1 до 1024 задают число интервалов между F1 и F2.
Направление перестройки определяется порядком F1 и F2: F2 может быть как выше,
так и ниже F1.

В режиме MD=6 сохранена фильтрация прежней FM6: четыре замера АЦП усредняются,
а изменение менее чем на два отсчёта игнорируется.

## I2C и Si5351

Для связи с Si5351 используется аппаратный TWI микроконтроллера. Драйвер
работает через стандартные регистры TWI, доступные во всех перечисленных
целевых ядрах. Отдельные реализации для ATmega328P, ATmega328PB и LGT8F328P
не требуются.

Вызов i2c_init(100000) выполняется при запуске до первого обращения к Si5351.
Драйвер рассчитывает TWBR с учётом F_CPU и аппаратных ограничений TWI:
- учитываются все четыре значения предделителя TWI;
- TWBR не опускается ниже 10;
- запрашиваемая частота ограничивается 400 кГц;
- если на малой частоте CPU запрошенные 100 кГц недостижимы, выбирается
  более низкая фактически допустимая частота.

Ожидание завершения операций TWI ограничено по времени. При сбое или отсутствии
ответа на шине драйвер не должен навсегда остановить выполнение микроконтроллера.
Для корректной работы I2C необходимы внешние подтягивающие резисторы SDA и SCL.

## Единая структура EEPROM

Пять записей по 16 байт. Все частоты задаются в герцах.

| Адрес | Метка | Назначение |
|---|---|---|
| 0x00 | XT= | Опорная частота кварца Si5351 |
| 0x10 | MD= | Режим работы: 5 или 6 |
| 0x20 | F1= | Частота при минимальном напряжении A0 |
| 0x30 | F2= | Частота при максимальном напряжении A0 |
| 0x40 | ST= | Количество шагов для режима MD=6 |

Все пять параметров присутствуют в EEPROM независимо от выбранного режима.
В MD=5 параметр ST просто не применяется.

Пример конфигурации по умолчанию:
- XT=27007840
- MD=5
- F1=2000000
- F2=1000000
- ST=0

Объём используемой конфигурации — 80 байт.

У ATmega168 доступно 512 байт EEPROM, у ATmega328P/328PB — 1024 байта.
У LGT8F328P библиотека ядра предоставляет стандартный Arduino EEPROM API
через эмуляцию EEPROM во Flash. Для эмуляции 1 КБ резервируется 2 КБ Flash;
пользовательская область составляет 1020 байт.

**Особенность LGT8F328P:** при загрузке нового скетча область эмулируемой EEPROM
очищается. После первого запуска FM7 обнаружит пустую конфигурацию и запишет
значения по умолчанию. Сохранённые через EEPROM API значения сохраняются при
обычном выключении питания, но не следует рассчитывать на их сохранение после
повторной загрузки прошивки.

Отдельная запись файла eeprom.hex через программатор для LGT8F328P в этой версии
не проверялась. Описанная ниже процедура отдельной записи EEPROM относится
к ATmega и не должна автоматически переноситься на LGT8F328P.

## Допустимые значения

Для параметров FM7 установлены проектные границы, принятые по результатам
практической проверки данной реализации:

- XT: 5 000 000...110 000 000 Гц;
- F1 и F2: 15 000...300 000 000 Гц;
- MD: только 5 или 6;
- ST: 0...1024.

Эти границы одинаково проверяются прошивкой и генератором EEPROM.

## Генератор EEPROM

Запустите make_eeprom.cmd. Скрипт PowerShell покажет текущие значения и
последовательно запросит:

1. XT — опорная частота кварца Si5351, Гц.
2. MD — режим 5 или 6.
3. F1 — частота при минимальном напряжении A0, Гц.
4. F2 — частота при максимальном напряжении A0, Гц.
5. ST — количество шагов (0 = 1024).

Нажатие Enter оставляет предложенное значение без изменений.
После ввода создаётся eeprom.hex с пятью Intel HEX-записями и контрольными
суммами.

Генератор распознаёт только новую структуру FM7. Переноса или преобразования
старых форматов FM5/FM6 нет.

Для ATmega файл eeprom.hex записывается отдельно через AVRDUDE_PROG 3.3:
- Memory: EEPROM
- Format: Intel HEX
- File: eeprom.hex

## Поведение при пустой или повреждённой EEPROM

При старте прошивка проверяет все пять меток, числовые значения и допустимые
диапазоны. Если новая конфигурация отсутствует или некорректна, записываются
значения по умолчанию, указанные в начале скетча.

Старые структуры EEPROM FM5/FM6 намеренно не мигрируются.

## Сборка

### ATmega168, ATmega168P/PA, ATmega328P и ATmega328PB

1. Установите MiniCore.
2. Выберите соответствующее семейство ATmega и нужный вариант кристалла.
3. Выберите реальный источник тактирования и частоту микроконтроллера.
4. Откройте 1freq-FM7.ino и выполните Verify/Compile.

Для ATmega168 следите за размером Flash: у этого микроконтроллера доступно
только 16 КБ.

### LGT8F328P

1. Установите ядро LGT8Fx.
2. В меню плат выберите LGT8F328.
3. Выберите вариант, соответствующий корпусу и плате (например, LQFP32).
4. Выберите фактический источник тактирования и делитель.
5. Откройте 1freq-FM7.ino и выполните Verify/Compile.

Фьюзы и конфигурация тактирования не изменяются автоматически. Выбирайте
настройки в соответствии с конкретной платой и её источником тактирования.

## Библиотеки и происхождение

Драйвер Si5351 взят из проекта Fmulder007/GSSx11, зафиксированный исходный commit:
https://github.com/Fmulder007/GSSx11/tree/17ef3410489f28bd740dc8ad943a304793417ece

I2C-драйвер FM7 использует аппаратный TWI и стандартные регистры AVR/LGT.
Инициализация шины выполняется непосредственно из setup().

Для LGT8F328P используется EEPROM API, поставляемый вместе с ядром LGT8Fx.
Для ATmega используется библиотека EEPROM выбранного ядра.

При адаптации не изменялась реализация алгоритмов расчёта Si5351.
