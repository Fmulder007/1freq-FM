# 1Freq-FM7 Programmer

Новая нативная программа находится в `Code/1freq-FM7/Programmer/`, рядом с прежним каталогом `Console`. Старую Console этот каталог не изменяет.

Программа предназначена для ATmega328P и USBasp. Она не использует .NET, JSON, каталоги настроек или резервных копий.

## Меню

1. **Работа с EEPROM-файлом** — редактирование XT, MD, F1, F2 и ST. Enter сохраняет предложенное предыдущее значение. Результат записывается в `eeprom.hex` в формате Intel HEX.
2. **Прошивка Firmware и Fuse** — фиксированные значения `LFUSE=62`, `HFUSE=D1`, `EFUSE=FF`, затем запись и проверка `ATmega328P.hex`.
3. **Прошивка EEPROM** — запись и проверка только пяти записей `eeprom.hex`, всего 80 байт по адресам `0x00`, `0x10`, `0x20`, `0x30`, `0x40`.
4. **Выход**.

Для всех операций USBasp AVRDUDE вызывается с параметром `-B 32kHz`.

## Пункт 2: Firmware и Fuse

Fuse сначала записываются и проверяются отдельным запуском AVRDUDE. Затем отдельным запуском записывается и проверяется Flash. Это важно, поскольку AVRDUDE выполняет Chip Erase перед записью Flash. Значение `HFUSE=D1` включает `EESAVE`, чтобы EEPROM сохранялась при Chip Erase. Пункт 2 не читает и не записывает EEPROM.

## Пункт 3: EEPROM

Файл предварительно проверяется: ровно пять Intel HEX data-записей по 16 байт, на адресах `0x00`, `0x10`, `0x20`, `0x30`, `0x40`, с правильными метками, допустимыми значениями и контрольными суммами. Другие адреса и записи не допускаются.

AVRDUDE получает только команды `-U eeprom:w:eeprom.hex:i` и `-U eeprom:v:eeprom.hex:i`. Flash и Fuse не меняются. Чтение EEPROM микроконтроллера не выполняется.

## Формат EEPROM

Каждая запись — 16 байт ASCII `TAG=число`, дополненные нулевыми байтами:

| Параметр | Адрес | Допустимые значения |
|---|---:|---:|
| XT | `0x00` | 5 000 000…110 000 000 |
| MD | `0x10` | только 5 или 6 |
| F1 | `0x20` | 15 000…300 000 000 |
| F2 | `0x30` | 15 000…300 000 000 |
| ST | `0x40` | 0…1024 |

Предыдущие значения читаются из находящегося рядом `eeprom.hex`. Если файла ещё нет, применяются прежние значения по умолчанию из профиля FM7: `XT=27007840`, `MD=5`, `F1=2000000`, `F2=1000000`, `ST=0`.

Начальный `eeprom.hex` совпадает с текущей конфигурацией `Code/1freq-FM7/eeprom.hex`.

## Сборка и упаковка

Исходный текст программы состоит из `1Freq-FM7-Programmer.c` и включаемых им фрагментов `programmer_piece_*.inc`. Это по-прежнему один компилируемый модуль C.

Для сборки требуется 32-битный MinGW-w64 GCC с MSVCRT-совместимой целью и поддержкой Windows XP SP3. Выполните `build-xp-x86.cmd`.

Затем выполните `package.cmd "путь-к-каталогу-AVRDUDE"`. Скрипт создаёт плоский комплект `dist\1Freq-FM7-Programmer` с EXE, `avrdude.exe`, `avrdude.conf`, `ATmega328P.hex`, `eeprom.hex`, `README.txt` и DLL-зависимостями AVRDUDE, если они нужны.

Цель приложения — Windows XP SP3 x86; также предусмотрены Windows 7/10/11 и x64 через WoW64. Совместимость именно готового бинарного комплекта и выбранной сборки AVRDUDE с Windows XP необходимо проверить запуском на реальной XP SP3: одной настройки subsystem version для такой проверки недостаточно.

После упаковки можно выполнить `1Freq-FM7-Programmer.exe --self-test`. Он проверяет HEX-файл EEPROM и Intel HEX прошивки Flash. Аппаратная проверка USBasp и записи в МК выполняется отдельно.
