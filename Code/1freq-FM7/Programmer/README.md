# 1Freq-FM7 Programmer

Распакуйте этот каталог `Programmer` рядом с прежним каталогом `Console`: `Code/1freq-FM7/Programmer/`. Скрипт упаковки берёт HEX прошивки из `../Console/Firmware/`, а начальный `eeprom.hex` франится рядом с исходником программы и соответствует актуальному `Code/1freq-FM7/eeprom.hex`.

Отдельная нативная консольная программа для прошивки ATmega328P через USBasp.
Программа не использует .NET, JSON, каталоги настроек или резервных копий.

## Меню

1. **Работа с EEPROM-файлом** — редактирование XT, MD, F1, F2 и ST. Enter сохраняет предложенное предыдущее значение. Результат записывается в `eeprom.hex` в формате Intel HEX.
2. **Прошивка Firmware и Fuse** — фиксированные Fuse `LFUSE=62`, `HFUSE=D1`, `EFUSE=FF`, затем запись и проверка `ATmega328P.hex`.
3. **Прошивка EEPROM** — запись и проверка только пяти записей `eeprom.hex`, всего 80 байт по адресам `0x00`, `0x10`, `0x20`, `0x30`, `0x40`.
4. **Выход**.

Для всех операций USBasp AVRDUDE вызывается с параметром `-B 32kHz`.

## Важная последовательность пункта 2

Fuse записываются и проверяются отдельным запуском AVRDUDE до запуска записи Flash. После этого отдельным запуском записывается Flash. Это необходимо потому, что AVRDUDE выполняет Chip Erase перед записью Flash. Значение `HFUSE=D1` программирует бит `EESAVE`, чтобы EEPROM сохранялась при Chip Erase. Пункт 2 не читает и не записывает EEPROM; восстановления EEPROM из файла здесь нет.

В пункте 3 используется только `-U eeprom:w:eeprom.hex:i`, затем `-U eeprom:v:eeprom.hex:i`. Для ATmega328P AVRDUDE задаёт страницу EEPROM размером 4 байта; пять непрерывных записей по 16 байт покрывают ровно 20 полных страниц (80 байт), без промежутков. Файл предварительно проверяется: ровно пять Intel HEX data-записей по 16 байт на ожидаемых адресах, правильные метки, диапазоны и контрольные суммы. Другие адреса и записи не допускаются.

## Формат EEPROM

Каждая запись — 16 байт ASCII `TAG=число`, дополненные нулевыми байтами:

| Параметр | Адрес | Допустимые значения |
|---|---:|---:|
| XT | `0x00` | 5 000 000…110 000 000 |
| MD | `0x10` | только 5 или 6 |
| F1 | `0x20` | 15 000…300 000 000 |
| F2 | `0x30` | 15 000…300 000 000 |
| ST | `0x40` | 0…1024 |

При запуске предыдущие значения берутся из находящегося рядом `eeprom.hex`. Если файла ещё нет, используются прежние значения по умолчанию из профиля FM7: XT=27007840, MD=5, F1=2000000, F2=1000000, ST=0.

## Сборка

Исходник `1Freq-FM7-Programmer.c` использует Win32 API для Unicode-консоли и запуска AVRDUDE. Для сборки требуется 32-битный MinGww-w64 GCC дапистся с MSVCRT-совместимой целью и поддержкой Windows XP. Выполнить `build-xp-x86.cmd`.

Скрипт `package.cmd "путь-к-каталогу-AVRDUDE"` собирает отдельный плоский комплект в `dist\1Freq-FM7-Programmer`. В каталог комплекта копируются приложение, `avrdude.exe`, `avrdude.conf`, прошивка из `../Console/Firmware/`, локальный `eeprom.hex` и DLL, если они находятся в каталоге выбранного AVRDUDE.

Целевая версия приложения — Windows XP SP3 x86; также предусмотрены Windows 7/10/11 и x64 через WoW64. Совместимость именно готового бинарного комплекта и выбранной сборки AVRDUDE с Windows XP необходимо подтвердить запуском на реальной XP SP3: одной настройки subsystem version для такой проверки недостаточно.

## Самопроверка

После упаковки можно запустить `1Freq-FM7-Programmer.exe --self-test`. Проверяются контрольные суммы Intel HEX, объём Flash и строгая схема EEPROM. Аппаратная проверка USBasp и записи в МК выполняется отдельно.
