# 1Freq-FM7 Programmer

Нативная консольная программа Windows x86 для работы с EEPROM и прошивкой ATmega328P через USBasp. Старый каталог Console не изменяется.

## Меню

1. **Считать EEPROM из микроконтроллера** — прочитать EEPROM и сохранить наши 80 байт (адреса 0x00–0x4F) в eeprom.hex.
2. **Редактировать EEPROM-файл** — изменить XT, MD, F1, F2 и ST.
3. **Прошивка Firmware и Fuse** — фиксированные LFUSE=62, HFUSE=D1, EFUSE=FF, затем запись и проверка ATmega328P.hex.
4. **Записать только EEPROM** — записать и проверить пять записей eeprom.hex.
5. **Выход**.

Для всех операций USBasp AVRDUDE вызывается с параметром -B 32kHz.

## Чтение EEPROM

Пункт 1 выполняет только чтение через AVRDUDE. Из бинарного дампа берутся первые 80 байт EEPROM и без изменений оформляются в пять Intel HEX data-записей по 16 байт на адресах 0x00, 0x10, 0x20, 0x30, 0x40.

Значения не проверяются по диапазонам и не обрезаются до 32 бит. Например, 9999999999 сохраняется без изменений. Если eeprom.hex уже существует, после успешного чтения он переименовывается в eeprom_old_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.hex. При ошибке чтения старый файл остаётся на месте. Содержимое EEPROM за пределами 0x00–0x4F не попадает в файл и не записывается.

## Редактор EEPROM

Каждый параметр показывается в одной строке:

XT частота опорного генератора 5000000 - 110000000 Гц [27007840]:
MD режим работы 5 или 6 [5]:
F1 частота при минимальном напряжении 15000 - 300000000 Гц [2000000]:
F2 частота при максимальном напряжении 15000 - 300000000 Гц [1000000]:
ST 0 - 1024 [0]:

Enter оставляет предыдущее значение. Поэтому ранее считанное значение за пределами диапазона можно сохранить, не меняя его. При вводе нового значения редактор применяет указанные ограничения. Поддерживаются числа до 13 десятичных цифр, помещающиеся в 16-байтовую запись EEPROM.

## Firmware и Fuse

Fuse сначала отдельно записываются и проверяются. Затем отдельно записываются и проверяются Flash. HFUSE=D1 включает EESAVE, чтобы EEPROM сохранялась при Chip Erase. Пункт 3 не читает и не записывает EEPROM.

## Запись EEPROM

Перед записью проверяется структура Intel HEX, метки и контрольные суммы. Диапазоны значений не проверяются: ранее считанные значения, например 9999999999, могут быть записаны обратно в МК. AVRDUDE получает только команды -U eeprom:w:eeprom.hex:i и -U eeprom:v:eeprom.hex:i. Flash и Fuse не меняются.

## Формат EEPROM

Каждая запись — 16 байт ASCII TAG=число, дополненные нулевыми байтами. Адреса: XT=0x00, MD=0x10, F1=0x20, F2=0x30, ST=0x40. Новые вводимые значения ограничены:

| Параметр | Допустимый диапазон |
|---|---:|
| XT | 5 000 000 – 110 000 000 Гц |
| MD | 5 или 6 |
| F1 | 15 000 – 300 000 000 Гц |
| F2 | 15 000 – 300 000 000 Гц |
| ST | 0 – 1024 |

## Сборка

Исходный модуль состоит из 1Freq-FM7-Programmer.c и включаемых им фрагментов programmer_piece_*.inc.

Сценарий .github/workflows/build-1freq-fm7-programmer.yml автоматически собирает 32-битный EXE для Windows XP SP3 на GitHub Actions. Используется переносной TDM-GCC 10.3.0; AVRDUDE выбирается после проверки архитектуры PE32 x86, версии подсистемы Windows, импортируемых API и запуска на Windows runner. Сборка проходит --self-test, включая проверку сохранения значения 9999999999.

Готовый комплект содержит EXE, AVRDUDE, конфигурацию, прошивку, eeprom.hex и необходимые DLL. Драйвер USBasp устанавливается в Windows отдельно. Фактическую работу на Windows XP SP3 и USBasp следует подтвердить на реальном компьютере.
