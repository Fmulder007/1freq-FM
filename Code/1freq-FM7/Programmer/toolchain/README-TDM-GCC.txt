TDM-GCC 10.3.0 TDM64 / MinGW-w64

This is the portable TDM-GCC distribution used by the Programmer build.
The build script invokes toolchain\bin\gcc.exe -m32, so the resulting
application is a 32-bit PE executable.

Official project:
https://jmeubank.github.io/tdm-gcc/
Official release:
https://github.com/jmeubank/tdm-gcc/releases/tag/v10.3.0-tdm64-2

The complete compiler distribution and its license files are included.
