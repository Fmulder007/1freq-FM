1Freq-FM7 Programmer
====================

НАЗНАЧЕНИЕ
----------
Консольная программа Windows x86 для программирования ATmega328P
через USBasp по интерфейсу ISP. Программа специализирована для проекта
1Freq-FM7, это не универсальный AVR-программатор.

ПОДХОДЯЩИЙ ПРОГРАММАТОР
-----------------------
Нужен USBasp — оригинальный Thomas Fischl или совместимый клон
с прошивкой USBasp. В программе жёстко задан протокол AVRDUDE:
-c usbasp. Скорость ISP также задана автоматически: 32 кГц (-B 32kHz).

USBtinyISP, Arduino as ISP, AVRISP/AVRISP mkII, CH341A и обычные
USB–UART адаптеры эта версия не поддерживает.

Нужен стандартный ISP-кабель USBasp (10 контактов) либо переходник
на 6 контактов. Должны быть подключены сигналы VCC, GND, RESET,
MOSI, MISO и SCK.

Драйвер USBasp для Windows устанавливается отдельно. Программа
не устанавливает драйвер и не использует COM-порт.

Официальное описание USBasp:
https://www.fischl.de/usbasp/

ПОДГОТОВКА К РАБОТЕ
------------------
1. Установите драйвер USBasp в Windows.
2. Подключите USBasp к компьютеру.
3. Подключите ISP-кабель к плате ATmega328P. Проверьте ориентацию
   разъёма и соответствие сигналов.
4. Убедитесь, что плата получает подходящее питание. Не включайте
   одновременно питание от USBasp и внешний источник, если это
   не предусмотрено схемой платы и положением перемычек.
5. Распакуйте комплект и запускайте EXE из его папки.

В одной папке с EXE должны лежать:
- avrdude.exe, avrdude.conf и DLL из комплекта;
- ATmega328P.hex — прошивка для пункта 3;
- eeprom.hex — настройки EEPROM для пунктов 2 и 4.

В переносном ZIP все перечисленные файлы уже находятся вместе.
Драйвер USBasp в комплект не входит.

Перед первой перепрошивкой уже настроенного устройства рекомендуется
сначала выполнить пункт 1 и сохранить текущую EEPROM.

МЕНЮ ПРОГРАММЫ
--------------
1 — СЧИТАТЬ EEPROM ИЗ МИКРОКОНТРОЛЛЕРА
    Считывает EEPROM и сохраняет первые 80 байт, адреса 0x00–0x4F,
    в eeprom.hex (пять записей по 16 байт). Байты сохраняются без
    изменения значений и без обрезания до 32 бит.
    Если eeprom.hex уже существует, после успешного чтения старый
    файл переименовывается в eeprom_old_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.hex.
    При ошибке чтения старый файл остаётся на месте.

2 — РЕДАКТИРОВАТЬ EEPROM-ФАЙЛ
    Меняет параметры в eeprom.hex. К микроконтроллеру не обращается.
    XT — опорная частота: 5 000 000–110 000 000 Гц, по умолчанию 27007840.
    MD — режим: 5 или 6, по умолчанию 5.
    F1 — частота при минимальном напряжении:
         15 000–300 000 000 Гц, по умолчанию 2000000.
    F2 — частота при максимальном напряжении:
         15 000–300 000 000 Гц, по умолчанию 1000000.
    ST — 0–1024, по умолчанию 0.
    Enter оставляет прежнее значение без изменения, даже если оно
    выходит за пределы диапазона редактора.

3 — ПРОШИВКА FIRMWARE И FUSE
    Сначала отдельно записывает и проверяет Fuse, затем записывает
    и проверяет Flash из ATmega328P.hex.
    Фиксированные Fuse:
      LFUSE=0x62, HFUSE=0xD1, EFUSE=0xFF.
    HFUSE=0xD1 включает EESAVE — сохранение EEPROM при Chip Erase.
    Пункт 3 не читает и не записывает eeprom.hex и не выполняет
    операцию записи EEPROM. При успешной записи и проверке HFUSE
    EEPROM должна сохраниться при стирании Flash.
    Значения Fuse предназначены для данного проекта.

4 — ЗАПИСАТЬ ТОЛЬКО EEPROM
    Проверяет формат eeprom.hex, записывает и проверяет ровно
    пять записей по 16 байт — 80 байт по адресам 0x00–0x4F.
    Flash и Fuse не меняет, EEPROM перед записью не считывает.
    Допускает корректно оформленные ранее считанные значения
    за пределами диапазонов редактора.

5 — ВЫХОД
    Завершает программу.

ФОРМАТ EEPROM
-------------
Файл eeprom.hex содержит пять Intel HEX data-записей по 16 байт:
  0x00 — XT
  0x10 — MD
  0x20 — F1
  0x30 — F2
  0x40 — ST
В каждой записи хранится ASCII-текст TAG=число с нулевым заполнением
до 16 байт. Всего программа читает и записывает область 80 байт.

СОВМЕСТИМОСТЬ И СБОРКА
----------------------
EXE — 32-битная Windows x86 программа с консольной подсистемой 5.01,
целевая совместимость — Windows XP SP3. На 64-битной Windows
используется подсистема WoW64. AVRDUDE x86 выбирается сборкой
после проверок PE32, версии подсистемы и импортируемых API.

Фактическую работу на Windows XP SP3 с конкретным USBasp и платой
нужно подтвердить на реальном оборудовании.

В каталоге Programmer рядом с EXE публикуются avrdude.exe,
avrdude.conf, все необходимые DLL, avrdude-build-info.txt и
ATmega328P.hex. Файл eeprom.hex также хранится здесь.
Для работы нужно скачать весь комплект файлов из одной папки.
Отдельно устанавливается только драйвер USBasp для Windows.

Локальная сборка: build-xp-x86.cmd (нужна папка toolchain
с TDM-GCC). Создание переносного комплекта: package.cmd.
Сборка GitHub Actions выполняет --self-test, проверяет формат EXE,
собирает переносной ZIP и обновляет в репозитории все runtime-файлы
рядом с программой.

ВАЖНО
-----
- Не отсоединяйте ISP-кабель во время операций.
- Не используйте пункт 3 с другим типом МК или другой конфигурацией Fuse.
- Для сохранения текущих настроек EEPROM сначала используйте пункт 1.
- Скорость ISP 32 кГц уже задана программой, менять её не нужно.
