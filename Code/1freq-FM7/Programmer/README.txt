1Freq-FM7 Programmer

Распаковать папку Programmer рядом с Console: Code\1freq-FM7\Programmer.

Программа для ATmega328P и USBasp.

Меню:
1 — Работа с EEPROM-файлом (XT, MD, F1, F2, ST).
2 — Прошивка Firmware и Fuse (LFUSE=62, HFUSE=D1, EFUSE=FF).
3 — Прошивка только EEPROM-файла (5 записей по 16 байт, адреса 00–4F).
4 — Выход.

Для USBasp фиксирована скорость ISP 32 кГц (-B 32kHz).

Пункт 2 сначала записывает и проверяет Fuse для запуском AVRDUDE,
затем отдельня прошивает и проверяет Flash. HFUSE=D1 включает EESAVE,
чтобы Chip Erase при записи Flash сохранял EEPROM. Пункт 2 не читает и
не записывает EEPROM.

Пункт 3 проверяет файл eeprom.hex и пишет только 80 байт по адресам
0x00, 0x10, 0x20, 0x30 и 0x40. Затем эти записи проверяются.
Flash и Fuse в пункте 3 не затрагиваются.

Все файлы комплекта должны лежать рядом с EXE.
Драйвер USBasp устанавливается пользователем отдельно.

Начальный eeprom.hex совпадает с текущей конфигурацией Code\1freq-FM7\eeprom.hex.
