1Freq-FM7 Programmer

Полный комплект для сборки
--------------------------
В полном архиве рядом с исходниками находится папка toolchain с
переносимым TDM-GCC 10.3.0 TDM64. Компилятор не нужно устанавливать
в Windows и не нужно добавлять в системный PATH.

Сборка
-----
Запустить build-xp-x86.cmd двойным щелчком.
Скрипт использует toolchain\bin\gcc.exe из этой папки и ключ -m32,
поэтому создаётся 32-битная программа.
Для EXE задана версия Windows Console Subsystem 5.01 (Windows XP).
Окно CMD не закрывается сразу: ошибки остаются видимыми.

Упаковка
--------
После сборки запустить package.cmd.
Скрипт создаёт dist\1Freq-FM7-Programmer — готовый плоский комплект
для запуска. В нём рядом лежат EXE, AVRDUDE, конфигурация, два HEX-файла
и нужные DLL.

Назначение меню
---------------
1 — Работа с EEPROM-файлом: XT, MD, F1, F2, ST.
2 — Прошивка Firmware и Fuse: LFUSE=62, HFUSE=D1, EFUSE=FF.
3 — Прошивка только EEPROM: пять записей по 16 байт, адреса 00–4F.
4 — Выход.

Для всех команд USBasp задана скорость ISP 32 кГц (-B 32kHz).

Пункт 2 отдельно записывает и проверяет Fuse, затем отдельно прошивает
и проверяет Flash. HFUSE=D1 включает EESAVE, поэтому Chip Erase при
записи Flash сохраняет EEPROM. Пункт 2 не читает и не записывает EEPROM.

Пункт 3 сначала проверяет eeprom.hex, затем записывает и проверяет
только 80 байт по адресам 0x00, 0x10, 0x20, 0x30 и 0x40.
Flash и Fuse в пункте 3 не затрагиваются.

Проверка EEPROM-файла
--------------------
eeprom.hex должен содержать ровно пять Intel HEX data-записей по
16 байт с адресами 00, 10, 20, 30 и 40, правильными метками и
контрольными суммами, а также запись EOF.

Подключение
-----------
Поддерживается ATmega328P с программатором USBasp.
Драйвер USBasp устанавливается в Windows отдельно.
Никакой ручной установки компилятора или настройки PATH не требуется.

Совместимость
-------------
Программа собирается как 32-битный Windows EXE с версией подсистемы 5.01.
Готовая сборка AVRDUDE выбирается автоматически только после проверки
архитектуры PE32 x86, версии подсистемы Windows и импортируемых API.
Фактическую работу на конкретном компьютере с Windows XP SP3 и USBasp
следует подтвердить подключением программатора и тестовой прошивкой.
