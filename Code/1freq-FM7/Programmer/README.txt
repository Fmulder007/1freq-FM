1Freq-FM7 Programmer

Меню
----
1 — Считать EEPROM из микроконтроллера.
2 — Редактировать EEPROM-файл: XT, MD, F1, F2, ST.
3 — Прошить Firmware и Fuse: LFUSE=62, HFUSE=D1, EFUSE=FF.
4 — Записать только EEPROM.
5 — Выход.

Для всех операций USBasp задана скорость ISP 32 кГц (-B 32kHz).

Чтение EEPROM
-------------
Пункт 1 считывает EEPROM через USBasp и сохраняет первые 80 байт
(адреса 0x00–0x4F) в eeprom.hex. Остальная EEPROM не попадает в файл.
Считанные байты сохраняются без проверки значений и без изменения
содержимого. Например, значение 9999999999 не обрезается до 32 бит.

Если рядом уже есть eeprom.hex, после успешного чтения старый файл
переименовывается в eeprom_old_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.hex.
При ошибке чтения существующий eeprom.hex остаётся на месте.

Редактирование EEPROM
---------------------
Параметры показываются по одному в строке:
XT частота опорного генератора 5000000 - 110000000 Гц [27007840]
MD режим работы 5 или 6 [5]
F1 частота при минимальном напряжении 15000 - 300000000 Гц [2000000]
F2 частота при максимальном напряжении 15000 - 300000000 Гц [1000000]
ST 0 - 1024 [0]

Enter оставляет прежнее значение. Это позволяет сохранить ранее
считанное значение, даже если оно выходит за диапазон нового ввода.
Если вводится новое значение, редактор проверяет указанный диапазон.
Файл записывается в формате Intel HEX: пять записей по 16 байт.

Прошивка Firmware и Fuse
------------------------
Пункт 3 отдельно записывает и проверяет Fuse-биты, затем отдельно
записывает и проверяет Flash. HFUSE=D1 включает EESAVE, поэтому
Chip Erase при записи Flash сохраняет EEPROM. Пункт 3 не читает
и не записывает EEPROM.

Запись EEPROM
-------------
Пункт 4 проверяет формат файла и записывает только пять записей по
16 байт по адресам 0x00, 0x10, 0x20, 0x30 и 0x40. Flash и Fuse
не затрагиваются. Допускаются ранее считанные числовые значения
за пределами диапазонов редактора, если запись имеет правильный формат.

Комплект и совместимость
------------------------
Для работы рядом с EXE должны находиться avrdude.exe, avrdude.conf,
ATmega328P.hex и eeprom.hex. USBasp-драйвер устанавливается в Windows
отдельно.

Программа собирается как 32-битный Windows EXE с версией консольной
подсистемы 5.01 (Windows XP). Сценарий GitHub Actions собирает EXE
с переносным TDM-GCC и подбирает AVRDUDE после проверки PE32 x86,
версии подсистемы Windows и импортируемых API.
Фактическую работу готового комплекта на Windows XP SP3 и USBasp
следует подтвердить на реальном компьютере.
