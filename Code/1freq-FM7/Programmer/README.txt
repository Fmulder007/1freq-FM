1Freq-FM7 Programmer

Полный комплект
---------------
В полном архиве 1Freq-FM7 Programmer рядом с программой находится папка
toolchain с переносимым TDM-GCC 10.3.0 (MinGW-w64/TDM64).
Компилятор запускается из этой папки и не требует установки в Windows
или изменения системного PATH.

Сборка
-----
Запустить build-xp-x86.cmd.
Скрипт использует toolchain\bin\gcc.exe и ключ -m32, поэтому создаётся
32-битная программа. Для EXE задаётся Windows Console Subsystem 5.01
(Windows XP). Окно CMD остаётся открытым, чтобы были видны сообщения.

Упаковка
--------
Запустить package.cmd. Он создаёт dist\1Freq-FM7-Programmer —
готовый плоский комплект для запуска и прошивки. Внутри каталога
должны находиться рядом:
  1Freq-FM7-Programmer.exe
  avrdude.exe
  avrdude.conf
  ATmega328P.hex
  eeprom.hex
  README.txt
  необходимые DLL AVRDUDE (если они есть в сборке)

Назначение меню
---------------
1 — Работа с EEPROM-файлом: XT, MD, F1, F2, ST.
2 — Прошивка Firmware и Fuse: LFUSE=62, HFUSE=D1, EFUSE=FF.
3 — Прошивка только EEPROM: пять записей по 16 байт, адреса 00–4F.
4 — Выход.

Для всех команд USBasp задана скорость ISP 32 кГц (-B 32kHz).

Пункт 2 отдельно записывает и проверяет Fuse, затем отдельно прошивает
и проверяет Flash. HFUSE=D1 включает EESAVE, поэтому Chip Erase при
записи Flash сохраняет EEPROM. Пункт 2 не читает и не записывает EEPROM.

Пункт 3 сначала проверяет eeprom.hex, затем записывает и проверяет
только 80 байт по адресам 0x00, 0x10, 0x20, 0x30 и 0x40.
Flash и Fuse в пункте 3 не затрагиваются.

Проверка EEPROM-файла
--------------------
eeprom.hex должен содержать ровно пять Intel HEX data-записей по
16 байт с адресами 00, 10, 20, 30 и 40, правильными метками и
контрольными суммами, а также запись EOF.

Подключение
-----------
Поддерживается ATmega328P с программатором USBasp.
Драйвер USBasp устанавливается в Windows отдельно. Zadig не требуется.
Все файлы, необходимые для запуска программы, лежат рядом с EXE.

Совместимость
-------------
Программа собирается как 32-битный Windows EXE с версией подсистемы 5.01.
TDM-GCC указывает поддержку 32-битных Windows-приложений начиная с XP.
Фактический запуск на конкретной установке Windows XP SP3 всё равно
нужно подтвердить испытанием на таком компьютере.
